# คำอธิบายข้อมูล (Data Description)

โฟลเดอร์นี้อธิบายข้อมูลที่ใช้ในโครงงาน **Analysis and Comparison of Mental Illness Across Countries**

## 1. แหล่งที่มาและสิทธิ์การใช้ข้อมูล

| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อชุดข้อมูล | Mental Health |
| แหล่งที่มาเดิม | https://www.kaggle.com/datasets/imtkaggleteam/mental-health |
| ประเภทข้อมูล | ข้อมูลสถิติสุขภาพจิตระดับโลก อนุกรมเวลา (Time-series) รายปี ครอบคลุมปี 1990 ถึง 2019 |

## 2. ไฟล์ในโฟลเดอร์นี้

| ตำแหน่งไฟล์ | คำอธิบาย |
| --- | --- |
| data/raw/1- mental-illnesses-prevalence.csv | ไฟล์ดิบตามที่ดาวน์โหลดมา **ห้ามแก้ไขด้วยมือ** มี 6,420 แถว 8 คอลัมน์ |
| data/processed/Mental_cleaned.csv | ข้อมูลที่ผ่านการทำความสะอาดแล้ว มี 6,420 แถว 9 คอลัมน์ **สร้างจาก** สคริปต์ประมวลผลข้อมูล |

วิธีสร้างไฟล์ที่ประมวลผลแล้วขึ้นใหม่: วางไฟล์ดิบที่ data/raw/1- mental-illnesses-prevalence.csv แล้วรันสคริปต์ Python สำหรับทำความสะอาดข้อมูล

## 3. พจนานุกรมข้อมูล (Data Dictionary) ของ Mental_cleaned.csv

ข้อมูลหลังจากทำความสะอาดแล้วมีทั้งหมด 6,420 แถว ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างในไฟล์ดิบก่อนการจัดการของแต่ละคอลัมน์

| คอลัมน์ | ชื่อคอลัมน์เดิม | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง (ในไฟล์ดิบ) |
| --- | --- | --- | --- | ---: |
| Entity | Entity | ข้อความ | ชื่อประเทศ หรือชื่อกลุ่มภูมิภาค/ระดับโลก | 0 |
| Code | Code | ข้อความ | รหัสประเทศแบบ 3 ตัวอักษร (ISO Code) | 270 |
| Entity_type | Entity type | ข้อความ | ประเภทของพื้นที่ เช่น Country (ประเทศ) หรือกลุ่มภูมิภาค | 0 |
| Year | Year | ตัวเลข | ปี ค.ศ. ของข้อมูล (ตั้งแต่ ค.ศ. 1990 - 2019) | 0 |
| Schizophrenia_pct | Schizophrenia disorders (%) | ตัวเลข | อัตราส่วนประชากรที่เป็นโรคจิตเภท (% ของประชากรทั้งหมด) | 0 |
| Depressive_pct | Depressive disorders (%) | ตัวเลข | อัตราส่วนประชากรที่เป็นโรคซึมเศร้า (% ของประชากรทั้งหมด) | 0 |
| Anxiety_pct | Anxiety disorders (%) | ตัวเลข | อัตราส่วนประชากรที่เป็นโรควิตกกังวล (% ของประชากรทั้งหมด) | 0 |
| Bipolar_pct | Bipolar disorders (%) | ตัวเลข | อัตราส่วนประชากรที่เป็นโรคไบโพลาร์ (% ของประชากรทั้งหมด) | 0 |
| Eating_pct | Eating disorders (%) | ตัวเลข | อัตราส่วนประชากรที่มีภาวะการกินผิดปกติ (% ของประชากรทั้งหมด) | 0 |

**หมายเหตุ**
- คอลัมน์ Code มีค่าว่าง 270 แถว เนื่องจากเป็นแถวข้อมูลในระดับภูมิภาค/โลก (Region/World) ที่ไม่มีรหัส ISO Code
- หน่วยของข้อมูลอัตราการพบโรคทั้งหมดคิดเป็นเปอร์เซ็นต์ (%) ของประชากรในแต่ละประเทศ/ภูมิภาค
